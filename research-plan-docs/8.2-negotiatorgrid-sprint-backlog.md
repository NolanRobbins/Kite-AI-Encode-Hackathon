## Critical Path

The longest dependency chain determines the minimum calendar time:

```
Day 1 (fork + Kite setup + contracts)
  → Day 2 (x402 on Kite verified + contract wiring)
    → Day 3 (NegMAS engine)
      → Day 4 (opponent model + gambit)
        → Day 5 (NegotiationExecutor + x402 settlement + attestation)  ← CRITICAL
          → Day 6 (e2e integration test)  ← P0 GATE
            → Day 7 (golden path demo)
              → Day 8-9 (MCP + API layer)
                → Day 10-11 (Dashboard)
                  → Day 12 (Video)
                    → Day 13-14 (Docs + Submit)
```

**Critical node**: Day 5 (task 5.1 — NegotiationExecutor). If the A2A ↔ NegMAS bridge takes longer than 2.5h, it pushes everything. Mitigation: have a simpler fallback (direct function calls instead of A2A messages) ready to swap in.
