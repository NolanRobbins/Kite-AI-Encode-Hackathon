## 1. Component Library Analysis

### 1.1 NegMAS BOA Framework — Frequency-Based Preference Estimation

**Sources**: [NegMAS docs](https://negmas.readthedocs.io/en/v0.10.23/tutorials/03.develop_new_negotiator.html), [RLBOA paper (AAMAS 2019)](https://www.ifaamas.org/Proceedings/aamas2019/pdfs/p260.pdf)  
**Confidence**: HIGH

The BOA (Bidding-Opponent-Acceptance) framework decouples negotiation strategy into three independent components. The **Opponent Model** component estimates the opponent's utility function from their bidding history.

#### How the Frequency Model Works

Two heuristics drive the model ([van Krimpen et al., 2013](https://doi.org/10.1007/978-3-642-30737-9_17)):
1. **Issue weight heuristic**: The opponent concedes less on important issues. If an issue's value stays the same across consecutive offers, its estimated weight increases.
2. **Value weight heuristic**: Preferred values appear more frequently. If a value appears often, its evaluation score increases.

#### Source Code (NegoLog ClassicFrequencyOpponentModel)

From [NegoLog/nenv/OpponentModel/ClassicFrequencyOpponentModel.py](https://github.com/aniltrue/NegoLog):

```python
class ClassicFrequencyOpponentModel(AbstractOpponentModel):
    issue_counts: Dict[Issue, float]            # Weight accumulator per issue
    value_counts: Dict[Issue, Dict[str, float]] # Frequency count per value
    alpha: float = 0.1                          # Learning rate

    def update(self, bid: Bid, t: float):
        self.opponent_bids.append(bid)
        for issue, value in bid:
            self.value_counts[issue][value] += 1.0
            # If this issue's value DIDN'T change from last offer → more important
            if len(self.opponent_bids) >= 2 and self.opponent_bids[-2][issue] == value:
                self.issue_counts[issue] += self.alpha * (1.0 - t)
                # Note: weight increase decays over time (1-t) — 
                # early unchanged values matter more
        self.update_weights()

    def update_weights(self):
        sum_issues = sum(self.issue_counts.values())
        for issue in self._pref.issues:
            self._pref[issue] = self.issue_counts[issue] / sum_issues  # normalize
            max_value = max(self.value_counts[issue].values())
            for value in issue.values:
                self._pref[issue, value] = self.value_counts[issue][value] / max_value
```

#### Key Design Insight for NegotiatorGrid

The `alpha * (1.0 - t)` decay factor means early rounds contribute more to weight estimation. In NegotiatorGrid's x402 negotiation, where sessions are short (5-10 rounds), this means the first 2-3 counteroffers are disproportionately informative. We should increase `alpha` for our use case.

### 1.3 Transformer-Based Opponent Modeling (kushalchawla/opponent-modeling)

**Sources**: [GitHub](https://github.com/kushalchawla/opponent-modeling), [Chawla et al. NAACL 2022 Findings](https://arxiv.org/abs/2203.12468)  
**Confidence**: MEDIUM

#### What It Does

The model infers the opponent's **priority ordering** (which issues they care about most) from the dialogue history. It uses a hierarchical encoder (BERT/RoBERTa/GPT-2 base) trained on the CraigslistBargain dataset.

#### Is It Relevant for Structured Bids?

**Partially.** The model is designed for **natural language negotiation dialogues**, not structured bid vectors. It processes utterances like "I really need the price to be under $50" and infers that price is the opponent's top priority.

**For NegotiatorGrid**: Our negotiation uses **structured offers** (price, SLA latency, round number) — not natural language. The transformer model would require:
- Retraining on structured bid sequences (no existing dataset)
- Converting bid vectors into a sequence format the model can process
- Training data generation via NegMAS simulation

**Verdict**: Too expensive for a 2-week hackathon. The frequency model (Section 1.1) already solves priority ordering for structured bids with zero training cost. **Skip for hackathon, revisit post-hackathon.**

**However**, we borrow one key insight: the **hierarchical encoding** of the negotiation history. Rather than treating each bid independently, we encode the full sequence of offers to capture temporal patterns (e.g., "opponent started aggressive but is now conceding"). We implement this via ASTRA's stance detection (Section 1.4) instead of a transformer.

### 1.4 ASTRA Stance Classification

**Sources**: [arXiv:2503.07129](https://arxiv.org/abs/2503.07129) (ASTRA, Kwon et al. 2025)  
**Confidence**: HIGH

ASTRA provides a principled framework for turn-level opponent modeling through fairness assessment and stance detection, followed by strategy-optimized counteroffers.

#### Stance Classification Formula

Given the opponent's score in their own offer at time \(t\):

\[
\Delta S_p = S_p^{P,(t)} - S_p^{P,(t-1)}
\]

\[
\text{Stance} = \begin{cases} \text{Generous} & \text{if } \Delta S_p < 0 \text{ (opponent asking for less)} \\ \text{Neutral} & \text{if } \Delta S_p = 0 \\ \text{Greedy} & \text{if } \Delta S_p > 0 \text{ (opponent asking for more)} \end{cases}
\]

#### Fairness Assessment

\[
\text{Fairness} = \begin{cases} \text{Fair} & \text{if } |S_a^P - S_p^P| \leq 4 \text{ or } S_p^P \leq \frac{PMS}{2} \\ \text{Unfair} & \text{otherwise} \end{cases}
\]

#### Nine Negotiation Tactics

**Collaborative** (5 tactics): Initial Concession, Continued-Smaller Concessions, Reciprocal Concessions, Logrolling, Mutual Gain Focus.

**Competitive** (4 tactics): Aggressive Early Offers, Response to Extreme Offer, No Concession Response, Reject Negative Concession.

#### Strategy Selection via LP Solver

The agent modulates \(\lambda\) (0 to 1) balancing self-interest vs. cooperation:

\[
\text{Objective: max } S_a + (1 - \lambda) \cdot S_p
\]

Dynamic \(\lambda\) based on stance:
- Greedy partner → \(\lambda \approx 0.9\) (competitive)
- Neutral partner → \(\lambda \approx 0.5\) (balanced)
- Generous partner → \(\lambda \approx 0.3\) (cooperative)

### 1.5 Bayesian Reservation Price Estimation

**Sources**: [Yu et al. 2015 (Knowledge-Based Systems)](https://documents.uow.edu.au/~minjie/pub-ps.dir/Knowledge-Base-System.pdf), [COMB (Chang & Fujita 2024)](https://link.springer.com/10.1007/s10726-024-09889-7), [IFAAMAS 2008](https://www.ifaamas.org/Proceedings/aamas08/proceedings/pdf/paper/AAMAS08_0385.pdf)  
**Confidence**: HIGH

#### Bayesian Update Rule

Hypothesis space \(H_w\) = all possible issue weight rankings (\(n!\) hypotheses for \(n\) issues).

After receiving counteroffer \(X_t\):

\[
P(h_m | X_t) = \frac{P(X_t | h_m) \cdot P(h_m)}{\sum_{k=1}^{n!} P(X_t | h_k) \cdot P(h_k)}
\]

Where the likelihood \(P(X_t | h_m) = \gamma^{h_m}\) is the Pearson correlation between:
- The opponent's estimated concession curve (based on hypothesis \(h_m\))
- The opponent's actual offer sequence

Higher correlation → higher likelihood → hypothesis \(h_m\) gets more probability mass.

#### Reservation Price Estimation

From the best hypothesis \(h_{max}\), we can estimate the opponent's reservation price by extrapolating their concession curve:

\[
V_t^{opp} = V_{max}^{opp} - (V_{max}^{opp} - V_{min}^{opp}) \cdot \left(\frac{t}{t_{max}}\right)^\alpha
\]

Where \(\alpha\) controls concession speed (Boulware: \(\alpha > 1\), Conceder: \(\alpha < 1\)).

For NegotiatorGrid, we simplify this to a **single-issue Bayesian update** (price only), since x402 negotiations are primarily about price:

\[
P(r_{opp} = v | \text{offers}) \propto \prod_{t} P(\text{offer}_t | r_{opp} = v)
\]

Where \(r_{opp}\) is the opponent's reservation price and each offer contributes evidence about where it lies.

### 2.3 Component 1: Frequency-Based Preference Estimator

Adapted from NegoLog's ClassicFrequencyOpponentModel for NegotiatorGrid's structured bid space.

```python
class NegGridFrequencyEstimator:
    """Estimates which issues the opponent cares most about."""
    
    ISSUES = ["price", "sla_latency_ms", "sla_uptime_pct"]
    
    def __init__(self, alpha: float = 0.25):  # Higher alpha for short sessions
        self.alpha = alpha
        self.issue_weights = {issue: 1.0 / len(self.ISSUES) for issue in self.ISSUES}
        self.offer_history: List[NegotiationOffer] = []
    
    def update(self, offer: NegotiationOffer, t: float):
        """Called when opponent makes a counteroffer.
        
        Args:
            offer: The opponent's offer
            t: Normalized time [0, 1] (round / max_rounds)
        """
        self.offer_history.append(offer)
        
        if len(self.offer_history) < 2:
            return  # Need at least 2 offers to compare
        
        prev = self.offer_history[-2]
        curr = self.offer_history[-1]
        
        # Issue weight heuristic: unchanged values → higher weight
        for issue in self.ISSUES:
            prev_val = getattr(prev, issue)
            curr_val = getattr(curr, issue)
            
            if prev_val == curr_val:
                # Opponent didn't concede on this issue → it's important to them
                self.issue_weights[issue] += self.alpha * (1.0 - t)
        
        # Normalize weights to sum to 1
        total = sum(self.issue_weights.values())
        self.issue_weights = {k: v / total for k, v in self.issue_weights.items()}
    
    @property
    def priority_ranking(self) -> List[str]:
        """Returns issues sorted by estimated opponent importance (most important first)."""
        return sorted(self.ISSUES, key=lambda i: self.issue_weights[i], reverse=True)
```

### 2.4 Component 2: Bayesian Reservation Price Estimator

Simplified from [Yu et al. 2015](https://documents.uow.edu.au/~minjie/pub-ps.dir/Knowledge-Base-System.pdf) for NegotiatorGrid's primarily single-issue (price) negotiation.

```python
import numpy as np
from scipy.stats import norm

class BayesianReservationEstimator:
    """Estimates the opponent's reservation price using Bayesian inference."""
    
    def __init__(self, 
                 price_range: tuple = (0.01, 10.0),  # USDT range for x402 services
                 resolution: int = 100,               # Discretization granularity
                 noise_sigma: float = 0.5):           # Observation noise
        self.price_range = price_range
        self.noise_sigma = noise_sigma
        
        # Discretize the price space into hypotheses
        self.prices = np.linspace(price_range[0], price_range[1], resolution)
        # Uniform prior
        self.posterior = np.ones(resolution) / resolution
        
        self.offers_received: List[float] = []
    
    def update(self, opponent_offer_price: float, t: float):
        """Update belief after observing opponent's counteroffer price.
        
        Key insight: An opponent's offer at time t reveals information about 
        their reservation price. They won't offer below their reservation,
        and their offers approach it as t → 1.
        
        Likelihood model: P(offer | reservation=r) is higher when the offer
        is consistent with a concession curve starting from their first offer
        and approaching r.
        """
        self.offers_received.append(opponent_offer_price)
        
        # Likelihood: P(observed_offer | reservation_price = r)
        # An offer of p is more likely if r is such that p lies on a
        # plausible concession curve toward r
        likelihoods = np.zeros_like(self.posterior)
        
        for i, r in enumerate(self.prices):
            if len(self.offers_received) == 1:
                # First offer: uniform likelihood (no concession info yet)
                # But: offer should be >= reservation price (sellers won't go below)
                likelihoods[i] = 1.0 if r <= opponent_offer_price else 0.01
            else:
                # Expected offer at time t given reservation price r
                # Using time-dependent concession model:
                # expected_offer(t) = first_offer - (first_offer - r) * t^alpha
                first_offer = self.offers_received[0]
                
                # Try multiple alpha values and take the best fit
                best_likelihood = 0.0
                for alpha in [0.5, 1.0, 2.0, 5.0]:  # Conceder to Boulware
                    expected = first_offer - (first_offer - r) * (t ** alpha)
                    # Gaussian likelihood around expected offer
                    likelihood = norm.pdf(opponent_offer_price, loc=expected, 
                                         scale=self.noise_sigma)
                    best_likelihood = max(best_likelihood, likelihood)
                
                likelihoods[i] = best_likelihood
        
        # Bayesian update
        self.posterior *= likelihoods
        total = self.posterior.sum()
        if total > 0:
            self.posterior /= total
        else:
            # Reset to uniform if all probabilities collapsed
            self.posterior = np.ones_like(self.posterior) / len(self.posterior)
    
    @property
    def estimated_reservation_price(self) -> float:
        """MAP estimate of opponent's reservation price."""
        return self.prices[np.argmax(self.posterior)]
    
    @property
    def reservation_price_interval(self) -> tuple:
        """95% credible interval for opponent's reservation price."""
        cumsum = np.cumsum(self.posterior)
        lower_idx = np.searchsorted(cumsum, 0.025)
        upper_idx = np.searchsorted(cumsum, 0.975)
        return (self.prices[lower_idx], self.prices[min(upper_idx, len(self.prices)-1)])
    
    @property
    def confidence(self) -> float:
        """Entropy-based confidence: 0 = uniform (no info), 1 = certain."""
        entropy = -np.sum(self.posterior * np.log(self.posterior + 1e-10))
        max_entropy = np.log(len(self.posterior))
        return 1.0 - (entropy / max_entropy)
```

### 2.5 Component 3: Stance Classifier (ASTRA-Inspired)

Adapted from [ASTRA (arXiv:2503.07129)](https://arxiv.org/abs/2503.07129) for structured bids.

```python
class StanceClassifier:
    """Classifies opponent's negotiation stance from their offer pattern."""
    
    def __init__(self):
        self.opponent_scores: List[float] = []  # Opponent's utility from their offers
        self.our_scores: List[float] = []        # Our utility from their offers
        self.stances: List[Stance] = []
    
    def update(self, offer: NegotiationOffer, our_utility: float, 
               opponent_utility_estimate: float):
        """Classify stance from the latest offer.
        
        Stance = direction of change in what the opponent asks for themselves.
        """
        self.opponent_scores.append(opponent_utility_estimate)
        self.our_scores.append(our_utility)
        
        if len(self.opponent_scores) < 2:
            self.stances.append(Stance.NEUTRAL)
            return
        
        # ASTRA formula: ΔS_p = S_p(t) - S_p(t-1)
        delta_sp = self.opponent_scores[-1] - self.opponent_scores[-2]
        
        # Threshold for noise tolerance (ASTRA uses 0, we use small epsilon)
        epsilon = 0.02  # 2% of price range
        
        if delta_sp < -epsilon:
            stance = Stance.GENEROUS  # Opponent asking for less → cooperating
        elif delta_sp > epsilon:
            stance = Stance.GREEDY    # Opponent asking for more → competing
        else:
            stance = Stance.NEUTRAL   # No significant change
        
        self.stances.append(stance)
    
    @property
    def current_stance(self) -> Stance:
        return self.stances[-1] if self.stances else Stance.NEUTRAL
    
    @property
    def dominant_stance(self) -> Stance:
        """Most frequent stance over the session (smooths noise)."""
        if not self.stances:
            return Stance.NEUTRAL
        from collections import Counter
        return Counter(self.stances).most_common(1)[0][0]
    
    def is_fair(self, possible_max_score: float) -> bool:
        """ASTRA fairness check: is the opponent's latest offer fair?"""
        if not self.our_scores or not self.opponent_scores:
            return True
        score_gap = abs(self.our_scores[-1] - self.opponent_scores[-1])
        return score_gap <= 0.1 * possible_max_score or \
               self.opponent_scores[-1] <= possible_max_score / 2
```

### 2.6 Component 4: Reputation-Aware Concession Engine

Integrates all three estimators with the ERC-8004 reputation score to determine target utility.

```python
class ReputationAwareConcessionEngine:
    """Determines concession strategy based on opponent model + reputation."""
    
    def __init__(self, 
                 base_aspiration: float = 0.95,     # Start high
                 min_aspiration: float = 0.4,        # Never go below this
                 max_rounds: int = 10):
        self.base_aspiration = base_aspiration
        self.min_aspiration = min_aspiration
        self.max_rounds = max_rounds
    
    def compute_lambda(self, stance: Stance, reputation_score: float) -> float:
        """Compute ASTRA's λ parameter (0=cooperative, 1=competitive).
        
        Modulated by ERC-8004 reputation:
        - High reputation opponent → we can afford to be slightly more cooperative
        - Low reputation opponent → stay competitive, protect our interests
        """
        # Base λ from stance (ASTRA values)
        stance_lambda = {
            Stance.GENEROUS: 0.3,
            Stance.NEUTRAL: 0.5,
            Stance.GREEDY: 0.9,
        }[stance]
        
        # Reputation adjustment: high reputation → decrease λ (more cooperative)
        # reputation_score is 0-100 from ERC-8004
        reputation_factor = (100 - reputation_score) / 100  # 0 for perfect, 1 for zero rep
        
        # Blend: reputation can shift λ by ±0.15
        adjusted_lambda = stance_lambda + 0.15 * (reputation_factor - 0.5)
        return max(0.0, min(1.0, adjusted_lambda))
    
    def compute_concession_rate(self, 
                                 stance: Stance,
                                 reputation_score: float,
                                 bayesian_confidence: float,
                                 estimated_reservation: float,
                                 our_reservation: float) -> float:
        """Compute α for the concession curve: V(t) = V_max - (V_max - V_min) * t^α
        
        α > 1: Boulware (concede slowly, then fast at deadline)
        α = 1: Linear
        α < 1: Conceder (concede fast, then slow)
        
        Rules:
        1. Greedy opponent → higher α (Boulware: don't reward greediness)
        2. Generous opponent → lower α (reciprocate with faster concession)
        3. High reputation → slightly lower α (trust-based cooperation)
        4. High Bayesian confidence → adjust based on ZOPA
        """
        # Base α from stance
        alpha = {
            Stance.GENEROUS: 1.5,   # Moderate Boulware — reciprocate but don't over-concede
            Stance.NEUTRAL: 3.0,    # Standard Boulware
            Stance.GREEDY: 8.0,     # Extreme Boulware — hold firm
        }[stance]
        
        # Reputation adjustment
        if reputation_score > 80:
            alpha *= 0.8  # Trust → concede a bit faster
        elif reputation_score < 30:
            alpha *= 1.3  # Distrust → concede even slower
        
        # ZOPA-aware adjustment
        if bayesian_confidence > 0.6 and estimated_reservation is not None:
            zopa_size = estimated_reservation - our_reservation
            if zopa_size > 0:
                # Large ZOPA → we can afford to concede more
                alpha *= max(0.5, 1.0 - zopa_size * 0.1)
            else:
                # No ZOPA detected → very high α (essentially no concession)
                alpha = 15.0
        
        return alpha
    
    def target_utility(self, round_number: int, alpha: float) -> float:
        """Compute target utility for this round using aspiration curve."""
        t = round_number / self.max_rounds
        aspiration = self.base_aspiration - \
                     (self.base_aspiration - self.min_aspiration) * (t ** (1.0 / alpha))
        return max(self.min_aspiration, aspiration)
```

### 2.7 Component 5: Cross-Session Learning via On-Chain Attestation

The opponent model persists across sessions by storing snapshots in the on-chain attestation trail (see Security Model document).

```python
import json
import hashlib

class CrossSessionLearner:
    """Persists opponent model state across negotiation sessions via on-chain attestation."""
    
    def __init__(self, attestation_contract, ipfs_client):
        self.attestation_contract = attestation_contract
        self.ipfs = ipfs_client
    
    def save_session(self, opponent_address: str, profile: OpponentProfile) -> str:
        """After negotiation, save opponent model to IPFS and attest on-chain."""
        model_snapshot = {
            "opponent_address": opponent_address,
            "sessions_count": profile.sessions_count,
            "issue_weights": profile.issue_weights,
            "estimated_reservation_price": profile.estimated_reservation_price,
            "concession_rate_alpha": profile.concession_rate_alpha,
            "stance_history": [s.value for s in profile.stance_history],
            "avg_agreed_price": profile.avg_agreed_price,
            "avg_rounds_to_agreement": profile.avg_rounds_to_agreement,
        }
        
        # Store full model on IPFS
        ipfs_hash = self.ipfs.add_json(model_snapshot)
        
        # Store hash on-chain as part of negotiation attestation
        model_hash = hashlib.keccak_256(
            json.dumps(model_snapshot, sort_keys=True).encode()
        ).hexdigest()
        
        return ipfs_hash, model_hash
    
    def load_session(self, opponent_address: str) -> OpponentProfile:
        """Before negotiation, load prior model from on-chain attestation data."""
        # Query attestation contract for latest model hash
        attestation = self.attestation_contract.functions.getLatestAttestation(
            opponent_address
        ).call()
        
        if attestation.transcript_uri:
            # Fetch model snapshot from IPFS
            snapshot = self.ipfs.get_json(attestation.transcript_uri)
            
            profile = OpponentProfile(opponent_address=opponent_address)
            profile.sessions_count = snapshot.get("sessions_count", 0)
            profile.issue_weights = snapshot.get("issue_weights", {})
            profile.estimated_reservation_price = snapshot.get("estimated_reservation_price")
            profile.concession_rate_alpha = snapshot.get("concession_rate_alpha", 1.0)
            profile.avg_agreed_price = snapshot.get("avg_agreed_price")
            profile.avg_rounds_to_agreement = snapshot.get("avg_rounds_to_agreement")
            
            # Reconstruct Bayesian prior from cross-session data
            # Instead of uniform, start with a Gaussian centered on last session's estimate
            profile.reservation_price_distribution = self._build_informed_prior(snapshot)
            
            return profile
        
        # No prior data — return fresh profile
        return OpponentProfile(
            opponent_address=opponent_address,
            erc8004_reputation_score=self._fetch_reputation(opponent_address)
        )
    
    def _build_informed_prior(self, snapshot: dict) -> dict:
        """Build an informed Bayesian prior from cross-session history.
        
        Key insight: If we estimated the opponent's reservation price as $2.50
        in the last session, we start the next session with a Gaussian prior
        centered at $2.50 instead of a uniform prior. This gives us a 
        significant head start in short negotiations.
        """
        if snapshot.get("estimated_reservation_price"):
            center = snapshot["estimated_reservation_price"]
            # Widen the prior based on number of sessions (more sessions → tighter prior)
            sigma = max(0.3, 2.0 / (1 + snapshot.get("sessions_count", 0)))
            return {"center": center, "sigma": sigma, "type": "gaussian"}
        return {"type": "uniform"}
```

## 3. Integrated NegotiatorGrid Opponent Model

### 3.1 The Complete Model Class

```python
class NegGridOpponentModel:
    """The complete hybrid opponent model for NegotiatorGrid.
    
    Implements NegoLog's AbstractOpponentModel interface contract:
    - name: str
    - update(bid, t): called on each opponent offer
    - preference: returns estimated preferences
    
    Adds NegotiatorGrid-specific capabilities:
    - Bayesian reservation price estimation
    - ASTRA-inspired stance classification
    - ERC-8004 reputation-weighted concession
    - Cross-session persistence via on-chain attestation
    """
    
    def __init__(self, 
                 opponent_address: str,
                 reputation_score: float,
                 prior_profile: OpponentProfile = None,
                 price_range: tuple = (0.01, 10.0),
                 max_rounds: int = 10):
        
        # Sub-components
        self.frequency = NegGridFrequencyEstimator(alpha=0.25)
        self.bayesian = BayesianReservationEstimator(
            price_range=price_range,
            noise_sigma=0.3
        )
        self.stance = StanceClassifier()
        self.concession = ReputationAwareConcessionEngine(max_rounds=max_rounds)
        
        # State
        self.opponent_address = opponent_address
        self.reputation_score = reputation_score
        self.round_number = 0
        self.max_rounds = max_rounds
        
        # Cross-session initialization
        if prior_profile and prior_profile.sessions_count > 0:
            self._warm_start(prior_profile)
    
    @property
    def name(self) -> str:
        return "NegGridHybridOpponentModel"
    
    def update(self, offer: NegotiationOffer, our_utility: float):
        """Process an opponent's counteroffer through all sub-models."""
        self.round_number += 1
        t = self.round_number / self.max_rounds
        
        # 1. Update frequency estimator
        self.frequency.update(offer, t)
        
        # 2. Update Bayesian reservation price estimate
        self.bayesian.update(offer.price, t)
        
        # 3. Classify stance
        # Estimate opponent's utility from their own offer using frequency weights
        opp_utility_est = self._estimate_opponent_utility(offer)
        self.stance.update(offer, our_utility, opp_utility_est)
    
    def recommend_target_utility(self) -> float:
        """The key output: what utility should we target in our next offer?"""
        current_stance = self.stance.current_stance
        
        # Compute concession parameters
        lam = self.concession.compute_lambda(current_stance, self.reputation_score)
        alpha = self.concession.compute_concession_rate(
            stance=current_stance,
            reputation_score=self.reputation_score,
            bayesian_confidence=self.bayesian.confidence,
            estimated_reservation=self.bayesian.estimated_reservation_price,
            our_reservation=0.0  # Injected by caller
        )
        
        return self.concession.target_utility(self.round_number, alpha)
    
    def recommend_tactic(self) -> str:
        """Select an ASTRA-style negotiation tactic."""
        stance = self.stance.current_stance
        fair = self.stance.is_fair(possible_max_score=1.0)
        
        if stance == Stance.GREEDY:
            if not fair:
                return "response_to_extreme_offer"  # Counter their extreme with our extreme
            return "no_concession_response"          # Hold firm
        elif stance == Stance.GENEROUS:
            return "reciprocal_concession"            # Reward cooperation
        else:  # NEUTRAL
            if self.round_number <= 2:
                return "aggressive_early_offer"       # Establish strong position early
            return "logrolling"                        # Trade on less important issues
    
    def get_diagnostics(self) -> dict:
        """Full model state for demo visualization and attestation."""
        return {
            "round": self.round_number,
            "frequency_weights": self.frequency.issue_weights,
            "priority_ranking": self.frequency.priority_ranking,
            "estimated_reservation_price": self.bayesian.estimated_reservation_price,
            "reservation_confidence": self.bayesian.confidence,
            "reservation_interval_95": self.bayesian.reservation_price_interval,
            "current_stance": self.stance.current_stance.value,
            "dominant_stance": self.stance.dominant_stance.value,
            "stance_history": [s.value for s in self.stance.stances],
            "reputation_score": self.reputation_score,
            "recommended_tactic": self.recommend_tactic(),
            "recommended_target_utility": self.recommend_target_utility(),
        }
    
    def _estimate_opponent_utility(self, offer: NegotiationOffer) -> float:
        """Estimate how much utility the opponent gets from their own offer."""
        weights = self.frequency.issue_weights
        # Higher price → higher utility for seller, lower for buyer
        # This is a simplification; in production, use the full frequency model
        price_norm = offer.price / 10.0  # Normalize to [0, 1]
        return weights.get("price", 0.33) * price_norm
    
    def _warm_start(self, profile: OpponentProfile):
        """Initialize model from cross-session data."""
        if profile.issue_weights:
            self.frequency.issue_weights = profile.issue_weights
        if profile.estimated_reservation_price:
            # Set informed Bayesian prior instead of uniform
            center = profile.estimated_reservation_price
            sigma = max(0.3, 2.0 / (1 + profile.sessions_count))
            from scipy.stats import norm
            self.bayesian.posterior = norm.pdf(self.bayesian.prices, 
                                               loc=center, scale=sigma)
            self.bayesian.posterior /= self.bayesian.posterior.sum()
```

## 6. Open Questions

1. **Frequency model α tuning**: With 5-10 round negotiations, should α be 0.25 (our current value) or higher? Could we run a NegMAS tournament to optimize this before the hackathon demo?
2. **Bayesian prior width for cross-session**: How much should we trust last session's reservation estimate? A sigma of 0.3 USDT may be too tight if the opponent changed strategy.
3. **Stance vs. strategy**: ASTRA classifies per-turn stance. Should we also classify overall strategy (Boulware/Conceder/Linear) using [Li et al. 2021](https://arxiv.org/abs/2107.01496)? This would give a more stable signal than per-turn stance.
4. **Privacy of opponent models**: Storing opponent model snapshots on IPFS (even hashed on-chain) exposes our estimation of their reservation price. Should we encrypt before IPFS upload?
5. **Multi-issue LP solver**: ASTRA uses LP for multi-issue optimization. For the hackathon, is NegMAS's `PresortingInverseUtilityFunction` sufficient, or should we implement the LP solver?
