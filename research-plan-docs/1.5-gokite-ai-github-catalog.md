### gokite-ai/AP2-kite — Fork of Google's AP2 with Kite-Specific Extensions

**Parent**: `google-agentic-commerce/AP2`
**Language**: Python
**Kite-Specific Commits**:
- `2025-10-03` — "add BuyWhenReady options, default payments, clean up run script"
- `2025-10-02` — "fix merchant agent"
- `2025-10-01` — "initial demo app"

**Can It Support Variable Pricing?**

YES. The `PaymentCurrencyAmount` class uses `value: float` — any numeric amount. The `CartMandate` contains a `PaymentRequest` with a `total` field that is set by the merchant at cart creation time. There is no hard-coded price floor or ceiling in the protocol itself. The cart is signed by the merchant (JWT in `merchant_authorization`), locking the price at that moment.

**NegotiatorGrid integration**: After negotiation concludes at price P:
1. Merchant agent creates a `CartMandate` with `total.amount.value = P`
2. Merchant signs the cart (JWT)
3. Buyer agent creates a `PaymentMandate` authorizing the payment
4. Settlement proceeds via Kite x402 or traditional payment rails

**Critical quote from the AP2 specification roadmap** (Section "Long-Term Vision"):
> "Native support for complex, multi-merchant transaction topologies" and "Support for real-time negotiations between buyer and seller agents"

This means NegotiatorGrid is building exactly what AP2 plans to support natively in its long-term roadmap. You're ahead of the spec.

## Action Items for NegotiatorGrid

1. **Study AP2-kite** — the only repo with Kite-specific payment protocol changes. The `BuyWhenReady` options and demo app show how Kite envisions agent commerce. NegotiatorGrid's negotiation phase maps to the period between `IntentMandate` (buyer expresses intent) and `CartMandate` (merchant locks price).

2. **The x402 repo is private.** You'll need to implement the `gokite-aa` scheme by following the Service Provider Guide's 402 response format and the weather demo as reference.

3. **developer-docs is your bible.** It's actively maintained (commit today) and contains everything from API references to integration guides.

4. **Fork AP2-kite for NegotiatorGrid.** Add a `NegotiationMandate` type between `IntentMandate` and `CartMandate` that captures the negotiation transcript, agreed price, and counterparty signatures. This would be a concrete protocol contribution.

5. **No ERC-8004 code exists anywhere in the org.** The identity system is conceptual / implemented in the closed-source platform layer, not as a public contract.

6. **The legacy Zettablock repos** (z*, zetta-*) are pre-rebrand artifacts. Ignore them entirely.
