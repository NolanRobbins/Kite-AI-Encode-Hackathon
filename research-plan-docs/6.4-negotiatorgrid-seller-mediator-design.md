## Section 1: x402 Dynamic Pricing Middleware (The Critical Question)

**Sources**:
1. https://github.com/coinbase/x402/blob/main/python/x402/http/types.py
2. https://blog.thirdweb.com/changelog/dynamic-pricing-for-x402-resources/
3. https://github.com/jordo1138/fastapi-x402
4. https://github.com/coinbase/x402

**Key Findings**:

- **No custom middleware required.** The official x402 Python SDK (coinbase/x402) natively supports dynamic per-request pricing via `DynamicPrice` callback functions. This is a first-class, documented feature—not a workaround.
- The `PaymentOption.price` field accepts either a static `Price` OR a `DynamicPrice = Callable[[HTTPRequestContext], "Price | Awaitable[Price]"]`. The callback receives the full HTTP request context, enabling buyer-specific pricing.
- NegotiatorGrid's integration pattern is: (1) maintain a `deal_store` dict mapping `buyer_address → agreed_price`, (2) implement a `negotiated_price()` callback that reads from `deal_store`, (3) pass it as `price=negotiated_price` in `PaymentOption`. After a negotiation completes, updating `deal_store` takes effect immediately for the next x402 request—no server restart, no middleware reload.
- The **thirdweb `upto` scheme** ([blog.thirdweb.com](https://blog.thirdweb.com/changelog/dynamic-pricing-for-x402-resources/)) is an alternative: the buyer pre-authorizes up to a maximum amount, the server does the work, then settles for the actual cost. Ideal for usage-based billing (e.g., per-token AI inference). Requires the thirdweb facilitator, not the Coinbase facilitator.
- The **`fastapi-x402`** package ([jordo1138/fastapi-x402](https://github.com/jordo1138/fastapi-x402)) uses a `@pay("$0.01")` decorator with a static price string. It does NOT support `DynamicPrice` natively. A wrapper function could supply a dynamic string, but this approach is inferior to the official SDK's callback mechanism.

**Confidence**: HIGH  
The `DynamicPrice` type is defined directly in `x402/python/x402/http/types.py` in the coinbase/x402 repository. The thirdweb blog post confirms the `upto` scheme is production-ready.

## Section 2: Seller Agent — 8-Step Loop

**Sources**:
1. https://negmas.readthedocs.io/en/v0.10.11/tutorials/02.develop_new_negotiator.html
2. https://yasserfarouk.github.io/anl/tutorials/Tutorial_run_a_negotiation/
3. https://pypi.org/project/negmas/0.9.6/
4. https://github.com/coinbase/x402/blob/main/python/x402/http/types.py

**Key Findings**:

- The seller's NegMAS negotiator should be a `SAONegotiator` subclass using `PolyAspiration` with `"boulware"` curve, starting at utility=1.0 and conceding slowly. This is the canonical `SmartAspirationNegotiator` pattern from the NegMAS documentation.
- Seller utility is the mirror of buyer utility: seller prefers **higher** price. The seller's reservation value (minimum acceptable price) is `min_price`.
- `TimeBasedConcedingNegotiator` (also in NegMAS) is a simpler alternative with the `offering_curve` parameter: `"boulware"`, `"linear"`, or `"conceder"`. Tournament data from NegMAS docs: Boulware scores 0.937 mean advantage vs Linear 0.849 vs Conceder 0.724—Boulware is the right default for a self-interested seller.
- The 8-step loop maps cleanly: LISTEN (FastAPI endpoint) → EVALUATE (on-chain read) → SET_STRATEGY (pure Python) → NEGOTIATE (NegMAS SAOMechanism) → COMMIT (EIP-712 sign + dict update) → [buyer sends x402 request] → SERVE (x402 middleware handles) → ATTEST (on-chain write).
- COMMIT is the key integration point between the negotiation layer and the x402 payment layer: `deal_store[buyer_address] = agreed_price` is the only code needed to activate negotiated pricing for that buyer.

**Confidence**: HIGH

**Open Questions**:
- Should the seller run NEGOTIATE synchronously (blocking the listener) or spawn a separate task per buyer?
- How does the seller detect if a buyer abandoned the negotiation mid-session (timeout handling)?
- Should `BuyerProfile.reputation_score` gate the strategy (e.g., score < 0.3 → refuse negotiation)?

### Step-by-Step Design Table

| Step | Function | Key Library | Latency | Failure Mode / Fallback | On-Chain Attestation |
|------|----------|-------------|---------|------------------------|----------------------|
| 1 | `publish(agent_card)` | web3.py, ipfshttpclient, x402 SDK | ~3s | IPFS timeout → retry with Pinata; mint failure → retry with higher gas | ERC-721 mint tx |
| 2 | `listen()` | FastAPI | 0ms (event-driven) | Connection drop → reconnect; malformed request → 400 | None |
| 3 | `evaluate_buyer(addr)` | web3.py | ~500ms | RPC timeout → use cached profile; unknown buyer → default NEUTRAL profile | None (read-only) |
| 4 | `set_strategy(profile, demand)` | pure Python | <5ms | N/A | None |
| 5 | `negotiate(request, strategy)` | negmas (SAOMechanism) | 100–500ms (5–10 rounds) | Timeout → walk away; deadlock → invite mediator | negotiation_id, tool_metadata_hash |
| 6 | `commit(deal)` | eth_account, dict update | <100ms | Sign failure → abort deal | deal_contract_hash (seller sig) |
| 7 | `serve(request)` | x402 SDK (FastAPI middleware) | 200ms–1s | Payment invalid → re-issue 402; service error → 503 | x402_payment_hash (facilitator) |
| 8 | `attest(deal, result)` | web3.py, ipfshttpclient | 2–3s | IPFS fail → log locally; tx fail → retry queue | NegotiationRecorded event |

class NegGridSellerNegotiator(SAONegotiator):
    """Seller-side negotiator for NegotiatorGrid.

    Strategy: SmartAspirationNegotiator pattern (NegMAS docs).
    - Starts at asking_price (best outcome for seller = highest price)
    - Concedes toward min_price using PolyAspiration curve
    - Never goes below min_price (hard reservation value)
    - Offers the outcome nearest to buyer's last offer, above aspiration level
    - Accepts buyer offers that match or exceed current aspiration level

    Source: https://negmas.readthedocs.io/en/v0.10.11/tutorials/02.develop_new_negotiator.html
    """

    def __init__(
        self,
        min_price: int,
        asking_price: int,
        curve: str = "boulware",
        *args,
        **kwargs,
    ):
        super().__init__(*args, **kwargs)
        self._min_price = min_price
        self._asking_price = asking_price
        self._curve = curve
        # PolyAspiration: starts at 1.0 (best), concedes per curve
        self._asp = PolyAspiration(1.0, curve)
        self._inv: Optional[PresortingInverseUtilityFunction] = None
        self._partner_last_offer: Optional[Any] = None
        self._min_util: float = 0.0
        self._max_util: float = 1.0
        self._best_outcome: Optional[Any] = None

    def on_preferences_changed(self, changes):
        from negmas.preferences.crisp_ufun import PreferencesChangeType
        changes = [c for c in changes if c.type not in (PreferencesChangeType.Scale,)]
        if not changes:
            return
        self._inv = PresortingInverseUtilityFunction(self.ufun)
        self._inv.init()
        worst, self._best_outcome = self.ufun.extreme_outcomes()
        self._min_util = float(self.ufun(worst))
        self._max_util = float(self.ufun(self._best_outcome))
        super().on_preferences_changed(changes)

    def respond(self, state, source: str = "") -> ResponseType:
        offer = state.current_offer
        if offer is None:
            return ResponseType.REJECT_OFFER
        self._partner_last_offer = offer
        # Accept if offer utility >= current aspiration level
        aspiration = self._asp.utility_at(state.relative_time)
        current_util = float(self.ufun(offer))
        scaled_aspiration = (self._max_util - self._min_util) * aspiration + self._min_util
        if current_util >= scaled_aspiration:
            return ResponseType.ACCEPT_OFFER
        return ResponseType.REJECT_OFFER

    def propose(self, state) -> Optional[Any]:
        if self._inv is None or self._best_outcome is None:
            return None
        # Current aspiration level (utility threshold)
        aspiration = self._asp.utility_at(state.relative_time)
        a = (self._max_util - self._min_util) * aspiration + self._min_util
        # Find outcomes above aspiration level
        outcomes = self._inv.some((a - 1e-6, self._max_util + 1e-6), False)
        if not outcomes:
            return self._best_outcome
        if self._partner_last_offer is None:
            import random
            return random.choice(outcomes)
        # Offer the outcome nearest to partner's last offer (above aspiration)
        nearest, ndist = None, float("inf")
        for o in outcomes:
            d = sum((x - y) ** 2 for x, y in zip(o, self._partner_last_offer))
            if d < ndist:
                nearest, ndist = o, d
        return nearest

async def negotiated_price(context: HTTPRequestContext) -> str:
    """DynamicPrice callback for x402 middleware.

    Called by the x402 SDK on every incoming request BEFORE payment verification.
    Returns the per-buyer negotiated price, or the default asking price.

    Source: coinbase/x402 python/x402/http/types.py DynamicPrice type.
    """
    buyer_address = context.adapter.get_header("X-BUYER-ADDRESS")
    if buyer_address:
        # Normalize to checksum address for dict lookup
        try:
            addr = Web3.to_checksum_address(buyer_address)
            if addr in deal_store:
                logger.debug(f"DynamicPrice: {addr} → {deal_store[addr]} (negotiated)")
                return str(deal_store[addr])
        except ValueError:
            logger.warning(f"Invalid buyer address in header: {buyer_address}")
    logger.debug(f"DynamicPrice: unknown buyer → {DEFAULT_ASKING_PRICE} (list price)")
    return str(DEFAULT_ASKING_PRICE)

            alpha = 1.0
        else:
            curve = ConcessionCurve.CONCEDER
            alpha = 0.3

        # Loyalty adjustments
        loyalty_discount = 0.0
        if buyer_profile.tier == "PREMIUM":
            loyalty_discount = 0.05
        elif buyer_profile.is_repeat_buyer and buyer_profile.default_rate < 0.1:
            loyalty_discount = 0.03

        starting_price = int(
            self.agent_card.asking_price * (1.0 - loyalty_discount)
        )

        logger.info(
            f"SET_STRATEGY: demand={demand_level:.2f}, curve={curve.value}, "
            f"start={starting_price}, min={self.agent_card.min_price}, "
            f"loyalty_discount={loyalty_discount:.1%}"
        )

        return SellerStrategy(
            curve=curve,
            starting_price=starting_price,
            min_price=self.agent_card.min_price,
            alpha=alpha,
            loyalty_discount=loyalty_discount,
        )

    # ── Step 5: NEGOTIATE ─────────────────────────────────────────────────────

    async def negotiate(
        self,
        request: NegotiateRequest,
        strategy: SellerStrategy,
    ) -> Optional[DealContract]:
        """Run NegMAS SAOMechanism from seller's perspective.

        The SAOMechanism runs synchronously (NegMAS is not async-native).
        Wrapped in asyncio.to_thread() to avoid blocking the FastAPI event loop.

        Seller utility function: maximize price
            u_seller(price) = (price - min_price) / (asking_price - min_price)
            u_seller at asking_price = 1.0 (best)
            u_seller at min_price = 0.0 (reservation value)

        Library: negmas (SAOMechanism, NegGridSellerNegotiator)
        Latency:  100–500ms for 5–10 rounds
        Attestation: negotiation_id, tool_metadata_hash (IPFS)
        Failure modes:
            - No agreement in max_rounds → return None (walk away)
            - Buyer leaves table → return None
            - Buyer offers below min_price throughout → walk away
        """
        # Price issue: discrete values from min_price to asking_price (step=10000 = $0.01)
        price_step = 10_000
        n_values = (strategy.starting_price - strategy.min_price) // price_step + 1
        issues = [make_issue(name="price", values=n_values)]

        # Create mechanism
        session = SAOMechanism(
            issues=issues,
            n_steps=request.max_rounds,
            time_limit=60.0,  # seconds wall-clock limit
        )

        # Seller utility: higher price = higher utility
        # Map discrete price index to actual price: price = min_price + idx * price_step
        seller_ufun = LUFun(
            values={"price": IdentityFun()},
            outcome_space=session.outcome_space,
            reserved_value=0.0,
        ).scale_max(1.0)

        # Buyer utility (modeled): lower price = higher utility (inverse)
        buyer_ufun = LUFun(
            values={"price": AffineFun(slope=-1, bias=n_values - 1)},
            outcome_space=session.outcome_space,
            reserved_value=0.0,
        ).scale_max(1.0)

        seller_negotiator = NegGridSellerNegotiator(
            min_price=strategy.min_price,
            asking_price=strategy.starting_price,
            curve=strategy.curve.value,
            name=f"seller_{request.negotiation_id[:8]}",
        )

        # Buyer negotiator is a proxy for the remote buyer agent
        # In the real system, the buyer agent sends offers via the FastAPI endpoint
        # For the hackathon demo, we simulate with AspirationNegotiator
        from negmas import AspirationNegotiator
        buyer_negotiator = AspirationNegotiator(
            name=f"buyer_{request.negotiation_id[:8]}",
            aspiration_type="conceder",  # buyers typically concede faster
        )

        session.add(seller_negotiator, preferences=seller_ufun)
        session.add(buyer_negotiator, preferences=buyer_ufun)

        # Run negotiation in thread pool (NegMAS is synchronous)
        result = await asyncio.to_thread(session.run)
        state = result

        if state.agreement is None:
            logger.warning(f"NEGOTIATE: no agreement for {request.negotiation_id}")
            return None

        # Convert outcome index back to price
        price_idx = state.agreement[0] if isinstance(state.agreement, tuple) else state.agreement["price"]
        agreed_price = strategy.min_price + int(price_idx) * price_step

        logger.info(
            f"NEGOTIATE: agreement at {agreed_price} micro-USDT "
            f"(${agreed_price/1e6:.4f}) after {state.step} rounds"
        )

        return DealContract(
            negotiation_id=request.negotiation_id,
            buyer_address=request.buyer_address,
            seller_address=self.account.address,
            service_type=request.service_type,
            agreed_price=agreed_price,
            timestamp=time.time(),
        )

    # ── Step 6: COMMIT ────────────────────────────────────────────────────────

    async def commit(self, deal: DealContract) -> str:
        """Sign DealContract with EIP-712 and update x402 middleware pricing.

        THIS IS THE KEY INTEGRATION POINT between the negotiation layer and x402.

        After this call:
        - deal_store[buyer_address] = agreed_price
        - The DynamicPrice callback negotiated_price() will return agreed_price
          for all subsequent x402 requests from this buyer
        - No middleware restart needed — just a dict update

        Library: eth_account (EIP-712 signing), in-memory dict update
        Latency:  <100ms (local operations, no on-chain tx)
        Attestation: deal_contract_hash (seller's EIP-712 signature)
        Failure modes:
            - Sign failure → log error, abort deal
        """
        # Build EIP-712 typed data
        typed_data = {
            "types": {
                "EIP712Domain": [
                    {"name": "name", "type": "string"},
                    {"name": "version", "type": "string"},
                    {"name": "chainId", "type": "uint256"},
                ],
                "DealContract": [
                    {"name": "negotiationId", "type": "string"},
                    {"name": "buyerAddress", "type": "address"},
                    {"name": "sellerAddress", "type": "address"},
                    {"name": "agreedPrice", "type": "uint256"},
                    {"name": "timestamp", "type": "uint256"},
                ],
            },
            "primaryType": "DealContract",
            "domain": {
                "name": "NegotiatorGrid",
                "version": "1",
                "chainId": KITE_CHAIN_ID,
            },
            "message": {
                "negotiationId": deal.negotiation_id,
                "buyerAddress": deal.buyer_address,
                "sellerAddress": deal.seller_address,
                "agreedPrice": deal.agreed_price,
                "timestamp": int(deal.timestamp),
            },
        }

        signed = self.account.sign_typed_data(
            domain_data=typed_data["domain"],
            message_types={"DealContract": typed_data["types"]["DealContract"]},
            message_data=typed_data["message"],
        )
        deal.seller_signature = signed.signature.hex()

        # ──────────────────────────────────────────────────────────────────
        # CRITICAL: Update deal_store — activates negotiated pricing in x402
        # ──────────────────────────────────────────────────────────────────
        buyer_addr = Web3.to_checksum_address(deal.buyer_address)
        deal_store[buyer_addr] = deal.agreed_price
        logger.info(
            f"COMMIT: deal_store[{buyer_addr}] = {deal.agreed_price} micro-USDT. "
            f"x402 middleware now serves negotiated price for this buyer."
        )

        # Compute deal contract hash for attestation
        deal_bytes = json.dumps(typed_data["message"], sort_keys=True).encode()
        deal.tool_metadata_hash = hashlib.sha256(deal_bytes).hexdigest()

        return deal.seller_signature

    # ── Step 7: SERVE ─────────────────────────────────────────────────────────

    async def serve(self, service_type: str, buyer_address: str) -> ServiceResponse:
        """Execute the paid service and return the result.

## Section 3: Mediator Agent Design

**Sources**:
1. https://github.com/hari7261/Negotiation-MultiAgent
2. http://fmwww.bc.edu/repec/esFEAM04/up.11191.1071763216.pdf (Nash Bargaining Solution)
3. https://www.ijcai.org/Proceedings/05/Papers/0518.pdf (Logical Model of NBS)
4. https://modelcontextprotocol.io/docs/learn/architecture
5. https://arxiv.org/html/2504.21030v1 (MCP for Multi-Agent Systems)

**Key Findings**:

- The hari7261/Negotiation-MultiAgent mediator ([GitHub](https://github.com/hari7261/Negotiation-MultiAgent)) uses a simple gap-detection heuristic: if `price_gap < avg_price * 0.05`, don't intervene; otherwise suggest the midpoint. NegotiatorGrid improves on this with the Nash Bargaining Solution (NBS) for mathematically grounded fair price computation.
- **Nash Bargaining Solution** for single-issue price negotiation: the fair price maximizes the product of both parties' utility gains over their reservation values. With linear utilities and symmetric bargaining power, this simplifies to the midpoint: `fair_price = (buyer_max + seller_min) / 2`. This is academically grounded ([IJCAI 2005](https://www.ijcai.org/Proceedings/05/Papers/0518.pdf)) and computable in O(1).
- **MCP as observation channel**: The MCP architecture ([modelcontextprotocol.io](https://modelcontextprotocol.io/docs/learn/architecture)) uses JSON-RPC 2.0 over HTTP or SSE. The mediator exposes an MCP server with a `negotiation/observe` tool. Both buyer and seller call `tools/call` on this server to post their offers, and the mediator accumulates the negotiation history. The `notifications/tools/list_changed` mechanism allows the mediator to push intervention proposals back to both agents.
- **Deadlock detection**: If the bid-ask spread has not narrowed by >10% across the last 3 rounds, the mediator classifies the negotiation as deadlocked and invokes the fair price formula.
- **Market context**: The mediator reads past NegotiationRecorded events from the on-chain attestation contract to compute average market prices per service type—providing grounded benchmarks, not just split-the-difference suggestions.
- **Why this impresses judges**: Three-agent protocol, novel MCP usage as a bidirectional observation channel (not just tool discovery), Nash Bargaining Solution with academic grounding, on-chain market data, and real-time visualization of three agents interacting simultaneously.

**Confidence**: HIGH (Nash Bargaining Solution), MEDIUM (MCP observation channel — novel pattern, no prior art in x402 context)

**Open Questions**:
- Should mediator intervention be opt-in (both agents must call `mediator/request_intervention`) or triggered automatically by the mediator after deadlock detection?
- How should the mediator handle cases where buyer_max < seller_min (ZOPA is empty, no deal possible)?
- Should `mediator_approved: true` in the DealContract provide any on-chain benefits (e.g., lower dispute bond)?

### Nash Bargaining Solution — Math

For single-issue price negotiation with linear utilities:

```
Buyer utility:  u_B(p) = (buyer_max - p) / (buyer_max - buyer_reservation)
Seller utility: u_S(p) = (p - seller_min) / (seller_asking - seller_min)

Nash Bargaining Solution:
    p* = argmax_p [u_B(p) - u_B^0] × [u_S(p) - u_S^0]

where u_B^0 = u_S^0 = 0 (disagreement utility = 0)

With linear utilities and symmetric power (τ = 0.5):
    p* = (buyer_max + seller_min) / 2

With asymmetric power (buyer power = τ, seller power = 1-τ):
    p* = τ × seller_min + (1-τ) × buyer_max
    Default: τ = 0.5 (symmetric)
```

# ══════════════════════════════════════════════════════════════════════════════
# negotiatorgrid/mediator_agent.py
# NegotiatorGrid Mediator Agent — MCP-enabled, Nash Bargaining Solution
# ══════════════════════════════════════════════════════════════════════════════

from __future__ import annotations

import asyncio
import json
import logging
import time
from dataclasses import dataclass, field
from typing import Any, Dict, List, Optional, Tuple

from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse
from web3 import Web3

logger = logging.getLogger(__name__)

KITE_RPC = "https://rpc-testnet.gokite.ai/"
KITE_CHAIN_ID = 2368
MIN_ROUNDS_BEFORE_INTERVENTION = 3      # Don't intervene in the first 3 rounds
DEADLOCK_THRESHOLD = 0.10               # Spread must narrow by >10% per 3-round window
DEADLOCK_WINDOW = 3                     # Number of rounds to check for progress


@dataclass
class OfferRecord:
    round_number: int
    proposer: str        # "buyer" | "seller"
    price: int           # micro-USDT
    timestamp: float


@dataclass
class NegotiationState:
    negotiation_id: str
    buyer_address: str
    seller_address: str
    service_type: str
    buyer_max: int              # buyer's ceiling price (from their AgentCard read)
    seller_min: int             # seller's floor price (reservation value)
    seller_asking: int          # seller's initial asking price
    offers: List[OfferRecord] = field(default_factory=list)
    fair_price: Optional[int] = None
    mediator_proposed: bool = False
    final_agreed_price: Optional[int] = None
    started_at: float = field(default_factory=time.time)


class MediatorAgent:
    """NegotiatorGrid Mediator Agent.

    Roles:
    1. Observes negotiations via MCP tool calls from buyer and seller
    2. Detects deadlock (spread not narrowing > 10% in last 3 rounds)
    3. Computes fair price using Nash Bargaining Solution
    4. Provides market context from on-chain attestation history
    5. Optionally: binding arbitration (both agents call accept_mediation)

    Architecture: FastAPI server exposing MCP-compatible JSON-RPC endpoints.
    MCP clients (buyer/seller agents) call tools via POST /mcp/tools/call.
    """

    def __init__(self, web3_rpc: str = KITE_RPC):
        self.w3 = Web3(Web3.HTTPProvider(web3_rpc))
        self._negotiations: Dict[str, NegotiationState] = {}
        # market_data[service_type] = list of past agreed prices
        self._market_data: Dict[str, List[int]] = {}

    # ── Observation ───────────────────────────────────────────────────────────

    def observe(
        self,
        negotiation_id: str,
        proposer: str,
        price: int,
        round_number: int,
        buyer_address: str = "",
        seller_address: str = "",
        service_type: str = "",
        buyer_max: int = 0,
        seller_min: int = 0,
        seller_asking: int = 0,
    ) -> dict:
        """Record a new offer in the negotiation history.

        Called by both buyer and seller via MCP tool invocation.
        Creates the NegotiationState on first call for a given negotiation_id.

        Returns current negotiation status and whether intervention is suggested.
        """
        if negotiation_id not in self._negotiations:
            state = NegotiationState(
                negotiation_id=negotiation_id,
                buyer_address=buyer_address,
                seller_address=seller_address,
                service_type=service_type,
                buyer_max=buyer_max,
                seller_min=seller_min,
                seller_asking=seller_asking,
            )
            self._negotiations[negotiation_id] = state
            logger.info(f"MEDIATOR: tracking negotiation {negotiation_id}")
        else:
            state = self._negotiations[negotiation_id]

        state.offers.append(OfferRecord(
            round_number=round_number,
            proposer=proposer,
            price=price,
            timestamp=time.time(),
        ))

        spread = self._current_spread(negotiation_id)
        should_intervene = self.should_intervene(negotiation_id)

        response = {
            "negotiation_id": negotiation_id,
            "round": round_number,
            "current_spread": spread,
            "offer_count": len(state.offers),
            "mediation_suggested": should_intervene,
        }

        if should_intervene and not state.mediator_proposed:
            fair = self.suggest_fair_price(negotiation_id)
            market_ctx = self.get_market_context(state.service_type)
            state.mediator_proposed = True
            response["mediator_intervention"] = {
                "fair_price": fair,
                "fair_price_usdt": fair / 1e6 if fair else None,
                "method": "nash_bargaining_solution",
                "market_context": market_ctx,
                "message": (
                    f"Deadlock detected. Nash Bargaining Solution suggests "
                    f"${fair/1e6:.4f} USDT. "
                    f"Market average for {state.service_type}: "
                    f"${market_ctx.get('avg_price_usdt', 'N/A')}. "
                    f"Call /mcp/tools/call with tool=accept_mediation to finalize."
                ),
            }

        return response

    def _current_spread(self, negotiation_id: str) -> Optional[int]:
        """Return the current bid-ask spread (last buyer offer vs last seller offer)."""
        state = self._negotiations.get(negotiation_id)
        if not state or len(state.offers) < 2:
            return None
        buyer_offers = [o.price for o in state.offers if o.proposer == "buyer"]
        seller_offers = [o.price for o in state.offers if o.proposer == "seller"]
        if not buyer_offers or not seller_offers:
            return None
        return seller_offers[-1] - buyer_offers[-1]

    # ── Deadlock Detection ────────────────────────────────────────────────────

    def should_intervene(self, negotiation_id: str) -> bool:
        """Detect negotiation deadlock.

        Deadlock conditions:
        1. At least MIN_ROUNDS_BEFORE_INTERVENTION rounds have occurred
        2. The bid-ask spread has not narrowed by > DEADLOCK_THRESHOLD
           in the last DEADLOCK_WINDOW rounds

        Reference: hari7261/Negotiation-MultiAgent mediator logic,
        enhanced with window-based spread convergence check.
        Source: https://github.com/hari7261/Negotiation-MultiAgent
        """
        state = self._negotiations.get(negotiation_id)
        if not state:
            return False

        n = len(state.offers)
        if n < MIN_ROUNDS_BEFORE_INTERVENTION * 2:
            return False

        # Compute spreads over last DEADLOCK_WINDOW rounds
        def spread_at(offset: int) -> Optional[float]:
            """Spread between the most recent buyer/seller offers as of offer index `offset`."""
            subset = state.offers[:offset]
            b = [o.price for o in subset if o.proposer == "buyer"]
            s = [o.price for o in subset if o.proposer == "seller"]
            if not b or not s:
                return None
            return float(s[-1] - b[-1])

        old_spread = spread_at(n - DEADLOCK_WINDOW * 2)
        new_spread = spread_at(n)

        if old_spread is None or new_spread is None or old_spread <= 0:
            return False

        # Deadlock if spread narrowed by less than DEADLOCK_THRESHOLD
        narrowing = (old_spread - new_spread) / old_spread
        is_deadlocked = narrowing < DEADLOCK_THRESHOLD

        if is_deadlocked:
            logger.info(
                f"MEDIATOR: deadlock detected for {negotiation_id}. "
                f"Spread narrowed {narrowing:.1%} (threshold: {DEADLOCK_THRESHOLD:.0%})"
            )

        return is_deadlocked

    # ── Fair Price Computation ────────────────────────────────────────────────

    def suggest_fair_price(
        self,
        negotiation_id: str,
        buyer_power: float = 0.5,
    ) -> Optional[int]:
        """Compute fair price using the Nash Bargaining Solution.

        For single-issue (price) negotiation with linear utilities:
            p* = τ × seller_min + (1-τ) × buyer_max

        where τ = buyer bargaining power (default 0.5 = symmetric).

        With τ=0.5: p* = (buyer_max + seller_min) / 2  (simple midpoint)

        If ZOPA is empty (buyer_max < seller_min), returns None.

        Sources:
        - IJCAI 2005: "A Logical Model of Nash Bargaining Solution"
          https://www.ijcai.org/Proceedings/05/Papers/0518.pdf
        - Rubinstein (1982) Alternating Offers → converges to NBS as δ→1
        """
        state = self._negotiations.get(negotiation_id)
        if not state:
            return None

        buyer_max = state.buyer_max
        seller_min = state.seller_min

        # Check ZOPA (Zone of Possible Agreement)
        if buyer_max < seller_min:
            logger.warning(
                f"MEDIATOR: ZOPA is empty for {negotiation_id}. "
                f"buyer_max={buyer_max} < seller_min={seller_min}. No deal possible."
            )
            return None

        # Nash Bargaining Solution (symmetric by default)
        fair_price = int(buyer_power * seller_min + (1 - buyer_power) * buyer_max)
        state.fair_price = fair_price

        logger.info(
            f"MEDIATOR: NBS fair price = {fair_price} micro-USDT "
            f"(${fair_price/1e6:.4f}). "
            f"buyer_max={buyer_max}, seller_min={seller_min}, τ={buyer_power}"
        )
        return fair_price

    # ── Market Context ────────────────────────────────────────────────────────

    def get_market_context(self, service_type: str) -> dict:
        """Return aggregate market stats from past on-chain attestations.

        Reads NegotiationRecorded events from the attestation contract,
        filtered by service_type, and returns summary statistics.

        In production: query the event log via web3.py.
        In hackathon demo: use in-memory market_data dict populated from
        IPFS-stored attestation records.
        """

        if not prices:
            # Load from chain (placeholder)
            prices = self._load_market_data_from_chain(service_type)
            self._market_data[service_type] = prices

        if not prices:
            return {
                "service_type": service_type,
                "transaction_count": 0,
                "avg_price_usdt": None,
                "min_price_usdt": None,

        avg = sum(prices) / len(prices)

            "min_price_usdt": round(min(prices) / 1e6, 4),
            "max_price_usdt": round(max(prices) / 1e6, 4),
            "p25_usdt": round(sorted(prices)[len(prices)//4] / 1e6, 4),
            "p75_usdt": round(sorted(prices)[3*len(prices)//4] / 1e6, 4),
        }

    # ── Binding Arbitration ───────────────────────────────────────────────────

    def accept_mediation(
        self,
        negotiation_id: str,
        agent_address: str,
    ) -> dict:
        """Register one party's acceptance of the mediator's suggested price.

        When both buyer and seller call this, the mediated price becomes binding.
        Returns the binding DealContract data (to be signed by both parties).
        """
        state = self._negotiations.get(negotiation_id)
        if not state or state.fair_price is None:
            return {"error": "no_fair_price_computed", "negotiation_id": negotiation_id}

        # Track acceptances (simplified — extend with cryptographic proof)
        if not hasattr(state, "_acceptances"):
            state._acceptances = set()
        state._acceptances.add(Web3.to_checksum_address(agent_address))

        both_accepted = (
            Web3.to_checksum_address(state.buyer_address) in state._acceptances
            and Web3.to_checksum_address(state.seller_address) in state._acceptances
        )

        if both_accepted:
            state.final_agreed_price = state.fair_price
            return {
                "status": "binding_agreement",
                "negotiation_id": negotiation_id,
                "agreed_price": state.fair_price,
                "agreed_price_usdt": state.fair_price / 1e6,
                "mediator_approved": True,
                "message": "Mediated agreement finalized. Both parties accepted Nash price.",
            }

        return {
            "status": "pending",
            "negotiation_id": negotiation_id,
            "waiting_for": "counterpart to call accept_mediation",
            "proposed_price": state.fair_price,
        }

# MCP-Compatible FastAPI Server for Mediator

def create_mediator_app(mediator: MediatorAgent) -> FastAPI:
    """Create FastAPI app exposing MCP tool interface for the mediator.

    MCP clients (buyer/seller) discover tools via GET /mcp/tools/list
    and invoke them via POST /mcp/tools/call (JSON-RPC 2.0 format).

    Source: MCP Architecture — https://modelcontextprotocol.io/docs/learn/architecture
    """
    app = FastAPI(title="NegotiatorGrid Mediator MCP Server", version="1.0.0")

    MCP_TOOLS = [
        {
            "name": "negotiation_observe",
            "title": "Observe Negotiation",
            "description": "Record a new offer in an observed negotiation. Called by buyer/seller each round.",
            "inputSchema": {
                "type": "object",
                "properties": {
                    "negotiation_id": {"type": "string"},
                    "proposer": {"type": "string", "enum": ["buyer", "seller"]},
                    "price": {"type": "integer", "description": "Price in micro-USDT"},
                    "round_number": {"type": "integer"},
                    "buyer_address": {"type": "string"},
                    "seller_address": {"type": "string"},
                    "service_type": {"type": "string"},
                    "buyer_max": {"type": "integer"},
                    "seller_min": {"type": "integer"},
                    "seller_asking": {"type": "integer"},
                },
                "required": ["negotiation_id", "proposer", "price", "round_number"],
            },
        },
        {
            "name": "market_context",
            "title": "Get Market Context",
            "description": "Get historical price statistics for a service type from on-chain data.",
            "inputSchema": {
                "type": "object",
                "properties": {
                    "service_type": {"type": "string"},
                },
                "required": ["service_type"],
            },
        },
        {
            "name": "accept_mediation",
            "title": "Accept Mediated Price",
            "description": "Accept the Nash Bargaining Solution price. Binding when both parties accept.",
            "inputSchema": {
                "type": "object",
                "properties": {
                    "negotiation_id": {"type": "string"},
                    "agent_address": {"type": "string"},
                },
                "required": ["negotiation_id", "agent_address"],
            },
        },
    ]

    @app.get("/mcp/tools/list")
    async def list_tools():
        """MCP tools/list endpoint — tool discovery for buyer/seller agents."""
        return {"tools": MCP_TOOLS}

    @app.post("/mcp/tools/call")
    async def call_tool(req: Request):
        """MCP tools/call endpoint — JSON-RPC 2.0 tool invocation."""
        body = await req.json()
        tool_name = body.get("params", {}).get("name") or body.get("name")
        arguments = body.get("params", {}).get("arguments") or body.get("arguments", {})
        req_id = body.get("id", 1)

        if tool_name == "negotiation_observe":
            result = mediator.observe(**arguments)
        elif tool_name == "market_context":
            result = mediator.get_market_context(arguments["service_type"])
        elif tool_name == "accept_mediation":
            result = mediator.accept_mediation(**arguments)
        else:
            return JSONResponse(content={
                "jsonrpc": "2.0",
                "id": req_id,
                "error": {"code": -32601, "message": f"Tool not found: {tool_name}"},
            })

        return JSONResponse(content={
            "jsonrpc": "2.0",
            "id": req_id,
            "result": {"content": [{"type": "text", "text": json.dumps(result)}]},
        })

    @app.get("/mcp/health")
    async def health():
        return {
            "status": "ok",
            "active_negotiations": len(mediator._negotiations),
            "tracked_service_types": list(mediator._market_data.keys()),
        }

    return app
