## 1. Frontend: Next.js on Vercel

### x402-next Middleware

The official `x402-next` package provides Next.js middleware for the seller side. For NegotiatorGrid's dashboard (which is the buyer/observer side), we use wagmi + viem for chain reads and the WebSocket hook for real-time negotiation data.

```bash
npm install x402-next viem wagmi @tanstack/react-query
```

**Source**: [x402-next README](https://github.com/x402-foundation/x402/tree/main/typescript/packages/legacy/x402-next)

### Edge Runtime Crypto Issue — SOLVED

**Problem**: Vercel's Edge Runtime does not support Node.js `crypto` module. Libraries like `ethers.js` and some wallet connectors use `crypto` internally, causing `Error: The edge runtime does not support Node.js 'crypto' module`.

**Solution**: viem/wagmi are Edge-compatible by design — they use Web Crypto API, not Node.js `crypto`. The fix for any middleware that needs Node.js APIs:

```typescript
// middleware.ts
export const config = {
  matcher: ['/dashboard/:path*'],
  runtime: "nodejs",  // ← Forces Node.js runtime instead of Edge
};
```

For the `x402-next` paymentMiddleware (seller side), the package already specifies `runtime: "nodejs"`:

```typescript
import { paymentMiddleware } from 'x402-next';

export const middleware = paymentMiddleware(
  "0xSellerAddress",
  {
    '/api/premium': {
      price: '$0.01',
      network: "base-sepolia",
      config: { description: 'NegotiatorGrid premium data' }
    },
  }
);

export const config = {
  matcher: ['/api/premium/:path*'],
  runtime: "nodejs",  // Required for x402-next
};
```

**Key Rule**: Never use `ethers.js` in Edge Runtime. Use `viem` instead. wagmi provides adapters if you need ethers compatibility.

**Source**: [Next.js Discussion #62985](https://github.com/vercel/next.js/discussions/62985), [wagmi Ethers Adapters](https://wagmi.sh/react/guides/ethers)

## 2. Backend: FastAPI on Railway

### Why Railway?

| Platform | WebSocket Support | Pricing | Pros | Cons |
|----------|------------------|---------|------|------|
| **Railway** | Native, persistent | $5/mo + usage | Zero-config Python, auto-deploy from GitHub, WS works OOTB | No free tier for WS |
| Render | Yes (Web Service tier) | $7/mo | Good docs, auto-deploy | WS can timeout on free tier |
| Fly.io | Yes (native) | Pay-as-you-go | Multi-region, fast | More complex config |
| AWS Lambda | No (use API Gateway WS) | Pay-per-invoke | Scalable | Complex WS setup, cold starts |

**Recommendation: Railway** for hackathon — zero-config WebSocket support, push-to-deploy, and affordable.

**Source**: [Railway FastAPI WebSocket](https://railway.com/deploy/fastapi-websocket-chat)

### Backend Entry Point

```python
# main.py
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from dotenv import load_dotenv
import os

load_dotenv()

app = FastAPI(title="NegotiatorGrid API")

app.add_middleware(
    CORSMiddleware,
    allow_origins=os.getenv("CORS_ORIGINS", "http://localhost:3000").split(","),
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

# Health check for Railway
@app.get("/health")
async def health():
    return {"status": "ok", "service": "negotiatorgrid-api"}

# Import routers
from routers.negotiation import router as negotiation_router
from routers.x402_payment import router as payment_router
from routers.attestation import router as attestation_router

app.include_router(negotiation_router, prefix="/api")
app.include_router(payment_router, prefix="/api")
app.include_router(attestation_router, prefix="/api")

# WebSocket endpoint
from ws.negotiation_stream import websocket_endpoint
app.websocket("/ws/negotiation/{session_id}")(websocket_endpoint)
```

### Hardhat Deploy Script

```typescript
// ignition/modules/NegotiatorGrid.ts
import { buildModule } from "@nomicfoundation/hardhat-ignition/modules";

export default buildModule("NegotiatorGrid", (m) => {
  const identityRegistry = m.contract("IdentityRegistry", []);
  const reputationRegistry = m.contract("ReputationRegistry", []);
  m.call(reputationRegistry, "initialize", [identityRegistry]);
  const dealRecord = m.contract("DealRecord", [identityRegistry, reputationRegistry]);
  return { identityRegistry, reputationRegistry, dealRecord };
});
```

```bash
npx hardhat ignition deploy ignition/modules/NegotiatorGrid.ts \

  --verify
```

## 6. GitHub Actions CI

### .github/workflows/ci.yml

```yaml
name: NegotiatorGrid CI

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

env:
  NODE_VERSION: "20"
  PYTHON_VERSION: "3.12"

jobs:
  # =========== LINT & TYPE CHECK ===========
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: ${{ env.NODE_VERSION }}
          cache: "npm"
          cache-dependency-path: frontend/package-lock.json
      - run: cd frontend && npm ci
      - run: cd frontend && npm run lint
      - run: cd frontend && npm run type-check

  # =========== SMART CONTRACT TESTS ===========
  contracts:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: ${{ env.NODE_VERSION }}
          cache: "npm"
          cache-dependency-path: contracts/package-lock.json
      - run: cd contracts && npm ci
      - run: cd contracts && npx hardhat compile
      - run: cd contracts && npx hardhat test
        env:
          KITE_RPC_URL: https://rpc-testnet.gokite.ai/
          PRIVATE_KEY: ${{ secrets.CI_PRIVATE_KEY }}

  # =========== BACKEND TESTS ===========
  backend:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: ${{ env.PYTHON_VERSION }}
          cache: "pip"
      - run: cd backend && pip install -r requirements.txt -r requirements-dev.txt
      - run: cd backend && pytest tests/ -v
        env:
          KITE_RPC_URL: https://rpc-testnet.gokite.ai/
          X402_FACILITATOR_URL: https://facilitator.pieverse.io
          OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}

  # =========== SMOKE TEST (end-to-end) ===========
  smoke:
    needs: [lint, contracts, backend]
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      
      - uses: actions/setup-node@v4
        with:
          node-version: ${{ env.NODE_VERSION }}
      
      - uses: actions/setup-python@v5
        with:
          python-version: ${{ env.PYTHON_VERSION }}
      
      # Start backend
      - run: |
          cd backend
          pip install -r requirements.txt
          uvicorn main:app --host 0.0.0.0 --port 8000 &
          sleep 5
        env:
          KITE_RPC_URL: https://rpc-testnet.gokite.ai/
          BUYER_PRIVATE_KEY: ${{ secrets.CI_PRIVATE_KEY }}
          SELLER_PRIVATE_KEY: ${{ secrets.CI_SELLER_KEY }}
          OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
          X402_FACILITATOR_URL: https://facilitator.pieverse.io
          DEAL_RECORD_ADDRESS: ${{ vars.DEAL_RECORD_ADDRESS }}
          CORS_ORIGINS: "*"
      
      # Smoke test: health check
      - run: curl -f http://localhost:8000/health
      
      # Smoke test: WebSocket connection
      - run: |
          python -c "
          import asyncio, websockets, json
          async def test():
              async with websockets.connect('ws://localhost:8000/ws/negotiation/test-session') as ws:
                  await ws.send(json.dumps({'type': 'PING'}))
                  response = await asyncio.wait_for(ws.recv(), timeout=5)
                  data = json.loads(response)
                  assert data.get('type') == 'PONG', f'Unexpected: {data}'
                  print('WebSocket smoke test PASSED')
          asyncio.run(test())
          "
      
      # Smoke test: Kite RPC connectivity
      - run: |
          curl -s -X POST https://rpc-testnet.gokite.ai/ \
            -H "Content-Type: application/json" \
            -d '{"jsonrpc":"2.0","method":"eth_chainId","params":[],"id":1}' \
            | python -c "
          import sys, json
          data = json.load(sys.stdin)
          chain_id = int(data['result'], 16)
          assert chain_id == 2368, f'Wrong chain: {chain_id}'
          print(f'Kite testnet connected: chain ID {chain_id}')
          "
      
      # Smoke test: Facilitator reachability
      - run: |
          curl -sf https://facilitator.pieverse.io/v2/supported | python -c "
          import sys, json
          data = json.load(sys.stdin)
          print(f'Facilitator supported: {json.dumps(data, indent=2)[:200]}')
          "

  # =========== DEPLOY CONTRACTS (manual trigger) ===========
  deploy-contracts:
    if: github.event_name == 'workflow_dispatch'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: ${{ env.NODE_VERSION }}
      - run: cd contracts && npm ci
      - run: |
          cd contracts
          npx hardhat ignition deploy ignition/modules/NegotiatorGrid.ts \
            --network kiteTestnet
        env:
          KITE_RPC_URL: https://rpc-testnet.gokite.ai/
          PRIVATE_KEY: ${{ secrets.DEPLOY_PRIVATE_KEY }}
```
