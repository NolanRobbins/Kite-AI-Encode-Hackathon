## 3. Coinbase MCP x402 Server Bridge

**Sources**: [Coinbase x402 MCP Server](https://docs.cdp.coinbase.com/x402/mcp-server), [Coinbase x402 Bazaar](https://docs.cdp.coinbase.com/x402/bazaar), [Simplescraper x402 Guide](https://simplescraper.io/blog/x402-payment-protocol)  
**Confidence**: HIGH

### Architecture

```
Claude Desktop → MCP Server (x402 client) → x402 API (paid endpoint)
                     ↓
              On 402 response:
              1. Parse PAYMENT-REQUIRED header
              2. Sign payment (EIP-3009/Permit2)
              3. Retry with PAYMENT-SIGNATURE
              4. Return 200 data to agent
```

### Full Bridge Code (TypeScript)

```typescript
import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";
import axios from "axios";
import { x402Client, wrapAxiosWithPayment } from "@x402/axios";
import { registerExactEvmScheme } from "@x402/evm/exact/client";
import { privateKeyToAccount } from "viem/accounts";
import { config } from "dotenv";

config();

const evmPrivateKey = process.env.EVM_PRIVATE_KEY as `0x${string}`;
const baseURL = process.env.RESOURCE_SERVER_URL || "http://localhost:4021";
const endpointPath = process.env.ENDPOINT_PATH || "/weather";

async function createClient() {
  const client = new x402Client();
  const evmSigner = privateKeyToAccount(evmPrivateKey);
  registerExactEvmScheme(client, { signer: evmSigner });
  return wrapAxiosWithPayment(axios.create({ baseURL }), client);
}

async function main() {
  const api = await createClient();

  const server = new McpServer({
    name: "NegotiatorGrid x402 Bridge",
    version: "1.0.0",
  });

  // Add paid tool
  server.tool(
    "get_weather",
    "Get weather data (x402-gated, ~$0.001 USDC)",
    { location: { type: "string", description: "City name" } },
    async ({ location }) => {
      const res = await api.get(`${endpointPath}?city=${location}`);
      return {
        content: [{ type: "text", text: JSON.stringify(res.data) }],
      };
    }
  );

  const transport = new StdioServerTransport();
  await server.connect(transport);
}

main();
```

### x402 Bazaar — The Official Discovery Layer

**The x402 Bazaar is Coinbase's own discovery mechanism**, codified as an official extension in v2 SDK (`@x402/extensions/bazaar`).

#### How It Works

1. **Servers** declare discovery metadata via `declareDiscoveryExtension()`
2. **Facilitators** extract and catalog metadata when processing payments (no separate registration step)
3. **Clients** query `GET {facilitator_url}/discovery/resources`

#### Discovery API

```bash
# CDP Facilitator
GET https://api.cdp.coinbase.com/platform/v2/x402/discovery/resources?type=http&limit=20

# x402.org testnet
GET https://x402.org/facilitator/discovery/resources

# By merchant wallet
GET https://api.cdp.coinbase.com/platform/v2/x402/discovery/merchant?payTo=0xYourAddress
```

### Key Finding for NegotiatorGrid

**Critical discovery**: The Bazaar auto-catalogs services after their first payment through a facilitator. This means:

1. Our mock seller agents register on the Bazaar simply by processing one payment through the x402.org or CDP facilitator
2. The Bazaar provides the `accepts` array with pricing — our negotiation engine can use this as the seller's opening price
3. **However**: the Bazaar has no filtering by trust/reputation — combine with x402Scout's ERC-8004 trust scores

**Template for NegotiatorGrid**: The Coinbase bridge code is directly reusable. Replace the single `get_weather` tool with our negotiation primitives: `negotiate_discover`, `negotiate_price`, `negotiate_pay`.

### Python Equivalent (for NegotiatorGrid)

No Python x402 SDK exists. We need to build the 402 interception at the HTTP layer:

```python
import httpx
import base64
import json
from eth_account import Account

async def x402_fetch(url: str, private_key: str, **kwargs):
    """Python x402 client - handles 402 Payment Required."""
    async with httpx.AsyncClient() as client:
        # First request
        response = await client.request(**kwargs, url=url)
        
        if response.status_code != 402:
            return response
        
        # Parse payment requirements
        payment_required = response.headers.get("payment-required")
        requirements = json.loads(base64.b64decode(payment_required))
        
        # Sign payment (EIP-3009 transferWithAuthorization)
        account = Account.from_key(private_key)
        payment_payload = sign_x402_payment(account, requirements)
        
        # Retry with payment
        headers = {**kwargs.get("headers", {})}
        headers["payment-signature"] = base64.b64encode(
            json.dumps(payment_payload).encode()
        ).decode()
        
        return await client.request(**kwargs, url=url, headers=headers)
```

## 4. Dynamic FastMCP (Ragie Open-Source)

**Sources**: [Ragie Blog](https://www.ragie.ai/blog/making-mcp-tool-use-feel-natural-with-context-aware-tools), [GitHub: ragieai/dynamic-fastmcp](https://github.com/ragieai/dynamic-fastmcp)  
**Confidence**: HIGH

### What It Is

An additive layer over the official MCP Python SDK that makes `list/tools` return **context-aware, runtime-resolved** tool descriptions. No forks, no protocol changes, no client-side modifications.

### Installation

```bash
pip install dynamic-fastmcp
# or add to pyproject.toml
```

### Core Architecture

```python
from dynamic_fastmcp.dynamic_fastmcp import DynamicFastMCP, DynamicTool
from mcp.server.fastmcp import Context

mcp = DynamicFastMCP()

@mcp.tool()
class DynamicEcho(DynamicTool):
    def name(self) -> str:
        return "dynamic_echo"
    
    def structured_output(self) -> bool | None:
        return True
    
    # Description resolved at runtime per request
    async def handle_description(self, ctx: Context) -> str:
        request = ctx.request_context.request
        return f"Echo tool for user: {request.user.username}"
    
    # Behavior also uses request context
    async def handle_call(self, text: str, ctx: Context) -> str:
        request = ctx.request_context.request
        return f"Echo to {request.user.username}: {text}"
```

### How It Works Under the Hood

From the [source code](https://github.com/ragieai/dynamic-fastmcp/blob/main/dynamic_fastmcp/dynamic_fastmcp.py):

```python
# DynamicTool Protocol
@runtime_checkable
class DynamicTool(Protocol):
    def name(self) -> str: ...
    def structured_output(self) -> bool | None: ...
    def handle_description(self, ctx: Context) -> Awaitable[str]: ...
    def handle_call(self, *args, **kwargs) -> Awaitable[Any]: ...

# DynamicToolManager extends ToolManager
class DynamicToolManager(ToolManager):
    _dynamic_tools: dict[str, DynamicToolWrapper]
    
    def _get_tool(self, name: str) -> Tool | DynamicToolWrapper | None:
        return self._tools.get(name) or self._dynamic_tools.get(name)

# DynamicToolWrapper resolves descriptions at call time
class DynamicToolWrapper(BaseModel):
    async def resolve_tool(self, context: Context) -> Tool:
        return Tool(
            fn=self.tool.handle_call,
            name=self.tool.name(),
            description=await self.tool.handle_description(context),
            parameters=self.parameters,
            # ...
        )
```

### Key Behavior

1. When `list/tools` is called, `DynamicToolManager` resolves each `DynamicTool`'s description by calling `handle_description(ctx)`
2. The resolved `Tool` objects are merged with static tools into the normal `list_tools()` response
3. Clients receive standard MCP `Tool` payloads — only descriptions are dynamic
4. Multi-tenant ready: same server instance, descriptions vary per API key / tenant

### Runtime Tool Registration/Deregistration

Dynamic FastMCP does NOT support adding/removing tools at runtime in the way Docker's `mcp-add`/`mcp-remove` does. It makes existing tool *descriptions* dynamic, not the tool *set* itself.

**However**, we can extend it for NegotiatorGrid:

```python
class NegotiatorGridMCP(DynamicFastMCP):
    """Extended DynamicFastMCP with runtime tool injection."""
    
    def __init__(self):
        super().__init__()
        self._discovered_services: dict[str, ServiceInfo] = {}
    
    async def add_discovered_service(self, service: ServiceInfo):
        """Add a newly discovered x402 service as a callable tool."""
        self._discovered_services[service.name] = service
        
        # Create a dynamic tool wrapping the remote service
        @self.tool()
        class DiscoveredServiceTool(DynamicTool):
            def name(self_tool) -> str:
                return f"x402_{service.name}"
            
            async def handle_description(self_tool, ctx: Context) -> str:
                return (
                    f"{service.description} "
                    f"[Price: ${service.price_usd} USDC | "
                    f"Trust: {service.trust_score}/100 | "
                    f"Latency: {service.latency_ms}ms]"
                )
            
            async def handle_call(self_tool, **kwargs) -> Any:
                return await x402_fetch(service.url, **kwargs)
        
        # Fire list_changed notification
        await self.notify_tools_changed()
    
    async def remove_discovered_service(self, name: str):
        """Remove a service from the session."""
        del self._discovered_services[name]
        # Remove from tool manager
        self._tool_manager._dynamic_tools.pop(f"x402_{name}", None)
        await self.notify_tools_changed()
```

### Key Finding for NegotiatorGrid

Dynamic FastMCP is our **server framework**. The `DynamicTool` protocol gives us:
- Runtime descriptions that include current price, trust score, latency
- Per-request context awareness (buyer's budget, negotiation state)
- Standard MCP wire format — works with any MCP client

We extend it with runtime tool injection (adding discovered x402 services as callable tools) and `notifications/tools/list_changed` to notify the agent of new tools.

### Step 5: NegotiatorGrid MCP Server (Buyer Side)

```python
from dynamic_fastmcp.dynamic_fastmcp import DynamicFastMCP, DynamicTool
from mcp.server.fastmcp import Context
import httpx

mcp = DynamicFastMCP(name="NegotiatorGrid")

# --- Primordial Negotiation Tools ---

@mcp.tool()
async def negotiate_discover(
    query: str,
    max_price_usd: float = 0.10,
    category: str = "data",
) -> dict:
    """Discover x402-gated services matching your needs.
    Searches x402Scout catalog and x402 Bazaar, returns ranked candidates
    with trust scores, pricing, and latency."""
    
    async with httpx.AsyncClient() as client:
        # Search x402Scout
        scout_resp = await client.get(
            "https://x402scout.com/discover",
            params={"query": query, "max_price_usd": max_price_usd, "category": category}
        )
        
        # Search x402 Bazaar
        bazaar_resp = await client.get(
            "https://x402.org/facilitator/discovery/resources",
            params={"type": "http", "limit": 20}
        )
        
        # Merge and rank by trust score
        candidates = merge_and_rank(scout_resp.json(), bazaar_resp.json())
        return {"candidates": candidates, "count": len(candidates)}


@mcp.tool()
async def negotiate_evaluate(service_url: str) -> dict:
    """Evaluate a service's trust, health, and x402 compliance
    before entering negotiation."""
    
    async with httpx.AsyncClient() as client:
        # Health check
        health = await client.get(
            "https://x402scout.com/health",
            params={"url": service_url}
        )
        
        # Trust score (ERC-8004)
        trust = await client.get(
            "https://x402scout.com/attest",
            params={"url": service_url}
        )
        
        # x402 compliance scan
        scan = await client.get(
            "https://x402scout.com/scan",
            params={"url": service_url}
        )
        
        return {
            "health": health.json(),
            "trust_score": trust.json(),
            "compliance": scan.json(),
        }


@mcp.tool()
async def negotiate_price(
    service_url: str,
    max_price_usd: float,
    strategy: str = "concession",  # concession, tit-for-tat, boulware
) -> dict:
    """Negotiate price with an x402-gated service.
    
    Runs bilateral negotiation engine:
    1. Probes service for posted price (via 402 challenge)
    2. Applies negotiation strategy with opponent modeling
    3. Returns agreed price or best counter-offer
    """
    
    # Probe for posted price
    async with httpx.AsyncClient() as client:
        probe = await client.get(service_url)
        if probe.status_code == 402:
            import base64, json
            requirements = json.loads(
                base64.b64decode(probe.headers["payment-required"])
            )
            posted_price = float(requirements[0]["maxAmountRequired"]) / 1e6
        else:
            posted_price = 0  # Free service
    
    # Run negotiation engine
    from negotiation_engine import bilateral_negotiate
    result = bilateral_negotiate(
        buyer_reservation=max_price_usd,
        seller_posted=posted_price,
        strategy=strategy,
        rounds=5,
    )
    
    return {
        "posted_price_usd": posted_price,
        "agreed_price_usd": result.agreed_price,
        "savings_pct": result.savings_percentage,
        "rounds": result.rounds_taken,
        "strategy_used": strategy,
    }


@mcp.tool()
async def negotiate_pay_and_call(
    service_url: str,
    agreed_price_usd: float,
    params: dict = {},
) -> dict:
    """Pay via x402 and call the service with agreed price.
    Signs EIP-3009 transferWithAuthorization, attaches to request,
    returns service response + payment receipt."""
    
    payment_payload = sign_x402_payment(
        private_key=BUYER_PRIVATE_KEY,
        amount_usd=agreed_price_usd,
        recipient=get_seller_wallet(service_url),
    )
    
    async with httpx.AsyncClient() as client:
        response = await client.get(
            service_url,
            params=params,
            headers={
                "payment-signature": base64_encode(payment_payload),
            }
        )
        
        return {
            "data": response.json(),
            "payment_receipt": response.headers.get("payment-response"),
            "cost_usd": agreed_price_usd,
        }


if __name__ == "__main__":
    mcp.run(transport="streamable-http")
```

2. **Kite testnet facilitator**: Can we use the Kite facilitator (`0x12343e...`) with x402Scout and the Bazaar, or are they Base-only? May need to run our own facilitator.

5. **Bazaar auto-catalog latency**: Services appear in the Bazaar only after first payment. For the demo, we need to trigger a payment to each mock service before the buyer discovers them.
